# Neonatal Respiratory Distress — Remotion video

A 45-second, 9:16 educational medical motion-graphics composition with 20 animated scenes and transitions.

## Run
```bash
npm install
npm run start
```

## Render MP4
```bash
npm run build
```

Composition: `NeonatalRespiratoryDistress` — 1080×1920, 30 fps, 1350 frames (45 seconds).

Arabic narration draft: `NARRATION_AR.txt`. Narration is separate and must be recorded/generated and added as an audio track; this source project currently renders animated visuals only.

Educational content only. Clinical management must follow local neonatal protocols and specialist assessment.
